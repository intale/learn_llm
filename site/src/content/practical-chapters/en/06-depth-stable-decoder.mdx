## The problem: depth adds more residual contributions

Each complete decoder block adds an attention output to the residual state,
then adds a feed-forward output. Increasing the block count repeats these
additions. The existing Xavier initializer uses a matrix's input and output
widths to choose its scale; those widths can stay fixed while the number of
residual additions grows. A suitable scale for one matrix therefore does not
settle how activations and loss sensitivity behave throughout the stack.

We will reduce the initial coefficients of the two projections that write
branch outputs into the residual state. This is a local initialization
heuristic. We will also observe the resulting decoder before training, using
the same occurrence-local contexts and valid-target mean loss as Chapter 5.

### Start with four selected coefficients

Take an illustrative output-projection vector $[0.2,-0.4,0,0.1]$. For one
complete block, keep it unchanged. For two blocks, multiply each coefficient
once by $1/\sqrt2\approx0.707107$. In their original order, the stored
coefficients are approximately $0.141421$, $-0.282843$, $0$ and $0.070711$.
For eight blocks, the factor is $1/\sqrt8\approx0.353553$, giving approximately
$0.070711$, $-0.141421$, $0$ and $0.035355$.

These decimal displays are rounded to six places; the Rust demo emits the
actual `f64` results. The vector illustrates the transformation, rather than
estimating a distribution from four values. An unselected query-projection
vector $[0.2,-0.4,0,0.1]$ remains unchanged at all three depths.

The selected matrices are `blocks.{b}.attention.output.weight` and
`blocks.{b}.ffn.down.weight`, where `{b}` is the zero-based block index. The
attention output projection writes the combined attention features back to
model width; the feed-forward down projection writes the SwiGLU features back
to that width. Query, key and value projections, gate and up projections,
embeddings and their tied vocabulary head, and all RMSNorm gains retain their
base values.

At fixed branch inputs, each selected projection is linear in its weights,
so multiplying those weights by the factor multiplies that branch's output by
the factor. In a whole decoder, later branch inputs also change. The final
decoder output is therefore not simply the unscaled output times one factor.

## Apply the factor once, using complete blocks

Use a positive number of complete decoder blocks, $L>0$, for the initialization
rule:

$$
\alpha=L^{-1/2},\qquad W_{\mathrm{stored}}=\alpha W_{\mathrm{base}}
$$

Apply this rule to each of the two selected matrices in every block. A block
has two residual additions, but the depth divisor remains the complete-block
count $L$. Eight blocks have $16$ additions and use $1/\sqrt8$, rather than
$1/\sqrt{16}$.

The transformation happens before forward execution. Forward uses
$W_{\mathrm{stored}}$ directly and adds no further factor. After initialization,
these stored coefficients may evolve normally when a later chapter trains the
model; they are not permanently constrained to remain a scaled base vector.

One block has factor $1$. The implementation returns its base decoder directly,
bypassing both transformation and reconstruction. It preserves parameter bits,
names, shapes and ordering, random-number consumption, forward values, loss and
parameter adjoints relative to the existing one-block constructor. The old
constructor still admits zero-block models; this new policy requires positive
depth because its factor is undefined at zero.

### What the variance intuition assumes

Consider a toy sum of $2L$ independent, zero-mean increments, each with variance
$\sigma^2$. Multiplying each increment by $\alpha$ gives

$$
\operatorname{Var}\left(\sum_{k=1}^{2L}\alpha r_k\right)
=2L\alpha^2\sigma^2=2\sigma^2.
$$

Here $r_k$ is one toy increment. Independence removes covariance terms, and
equal variance gives the same contribution for each increment. This calculation
motivates the depth factor. Real attention and feed-forward branches depend on
shared residual states, and their Jacobians can be correlated. They do not
satisfy this toy model in general, so the calculation is no proof of stable
activations, gradients or training for the decoder.

### Differentiate the coefficient actually stored

For a scalar product with input $2$, write $y=2w_{\mathrm{stored}}$. Its
derivative is

$$
\frac{\partial y}{\partial w_{\mathrm{stored}}}=2.
$$

If instead we keep a base coordinate in the graph and define
$w_{\mathrm{stored}}=\alpha w_{\mathrm{base}}$, the chain rule gives

$$
\frac{\partial y}{\partial w_{\mathrm{base}}}=2\alpha.
$$

Our decoder stores the initialized coefficient as the parameter. Its gradient
is with respect to that stored coefficient, so it receives no second automatic
depth factor. The two coordinate choices do not imply equal parameter updates
under an optimizer, nor do these derivatives imply convergence.

### Measure residual magnitude and completed loss sensitivity

For residual values $x$ at $n$ valid token positions with $d$ features each,
define root mean square as

$$
\operatorname{RMS}(x)
=\sqrt{\frac{1}{nd}\sum_{t\in\mathcal V}\sum_{c=1}^{d}x_{tc}^{2}}.
$$

$\mathcal V$ is the set of valid positions and has size $n$; $c$ indexes
features. RMS measures magnitude about zero. It does not subtract a mean and
is not centered variance. RMSNorm also does not center activations or establish
unit variance.

Record the input residual as site $0$, then the state after each attention
addition and each feed-forward addition in forward order. Adjacent blocks
share a boundary, which is counted once. There are $2L+1$ sites, ending at
site $2L$ before final model RMSNorm and the tied vocabulary head.

Let $A_s$ be activation RMS at site $s$. Let $G_s$ be RMS of the fully
accumulated derivative of the existing valid-target mean cross entropy with
respect to that site's residual features. The mean loss uses natural logarithms
and is reported in nats per valid target. Its derivatives describe sensitivity
of that same objective; they are not parameter-gradient norms or partial
contributions from one backward edge.

Use two different normalizers:

$$
a_s=\frac{A_s}{A_0},\qquad g_s=\frac{G_s}{G_{2L}}.
$$

$a_s$ and $g_s$ are dimensionless ratios. Activations are compared with the
input magnitude. Adjoint magnitudes are compared with the terminal residual
adjoint, before the final RMSNorm and tied head; those later operations still
contribute to that terminal derivative. The normalization fixes $a_0=1$ and
$g_{2L}=1$. It does not fix the absolute magnitudes of either normalizer.

Both normalizers must be positive and finite. Zero or nonfinite values are
errors; the observer does not add an epsilon to make a ratio reportable. It
includes only valid-position features, skipping padding before arithmetic, and
uses an overflow-safe RMS reduction. Multiplying a padded NaN by zero would
not exclude it safely. Empty validity, nonfinite valid values and missing
completed adjoints are also errors.

The observer selects residual handles by exact node identity after the existing
reverse pass has accumulated all their contributions. RMS calculations take
place outside the differentiation graph. Observation adds no graph operations,
random draws or changes to weight values; the usual mean-loss reverse pass
still produces the decoder's parameter gradients.

## History: fan-based scale and depth-aware residual methods

Fan-in and fan-out reasoning sets a matrix's initialization scale under simplified assumptions; it does not by itself account for repeated additions in this residual decoder.

[Glorot and Bengio's 2010 paper](https://proceedings.mlr.press/v9/glorot10a.html)
studies activation and backward-gradient variance near initialization.

Section 4.2 derives fan-in and fan-out variance conditions in an approximately linear regime with independently initialized weights and equal input-feature variances, and gives a compromise normalized initialization.

Fan-in counts the inputs to a matrix and fan-out counts its outputs. Their
compromise initialization targets ideal
weight variance $2/(\mathrm{fan\_in}+\mathrm{fan\_out})$.

For a $4\times4$ matrix, the existing Xavier uniform initializer therefore has
ideal half-bound $\sqrt{3/4}$ and variance $1/4$. Multiplying a selected matrix
by $\alpha$ multiplies its half-bound by $\alpha$ and its ideal variance by
$\alpha^2$.

<summary id="depth-practice-answer-summary">Explanations for factors, site counts, derivatives, thresholds and construction states</summary>

1. The factors are $1$, $1/\sqrt2$ and $1/\sqrt8$. Multiplying only the
   selected vector gives the coefficient values explained above; the query
   vector stays $[0.2,-0.4,0,0.1]$. For a selected $4\times4$ matrix, the ideal
   half-bounds are $\sqrt{3/4}$, $\sqrt{3/8}$ and $\sqrt{3/32}$, with variances
   $1/4$, $1/8$ and $1/32$. The variance changes by the square of the factor.
   These are distribution properties, not a finite-sample measurement.
2. Eight complete blocks contain $16$ residual additions. The input plus each
   addition's output gives $17$ sites; a block's final state is the next block's
   input and is counted once. The divisor remains $L=8$.
3. $\partial y/\partial w_{\mathrm{stored}}=2$, while
   $\partial y/\partial w_{\mathrm{base}}=2\alpha$ when the transformation is
   retained in the graph. Our parameter is the stored coefficient. Multiplying
   again in forward would change the intended initialized model.
4. $101>100$ puts the first synthetic array's site $3$ above the band.
   $0.001<0.01$ puts the second array's site $0$ below it. Equality at $0.01$
   or $100$ is allowed. The actual four initialized decoder reports lie within
   the band and are separate observations.
5. The deeper fixed initialized fixtures have lower observed maximum ratios
   than their same-base controls; the one-block observations coincide. All
   controls also pass. Activation RMS divides by input RMS and adjoint RMS by
   terminal residual-adjoint RMS, so each denominator must be positive and
   finite. Ratios omit absolute scale and cover these fixtures before training,
   so they establish neither adequate absolute derivatives nor convergence.
6. Dropping preparation leaves the caller RNG unchanged, as does refusal.
   Checked parameter and position bounds precede model-array allocation.
   Fresh initialization refuses `Initialized` and `Restored` states before
   draws or mutation. Restoration takes a construction record and actual
   stored parameters and does not rescale. The laptop entry has metadata and
   arithmetic only, with no parameter arrays or execution to restore.

## Carry explicit construction choices into the decoder core

Depth-aware initialization changes the starting output projections. It retains
the selected source pairs, local positions, occurrence-local causal ranges and
valid-target mean loss from Chapter 5. More blocks must preserve those boundaries;
initialization cannot repair an incorrectly joined context or target.

Chapter 7 will place decoder dimensions and construction choices in a configurable
core. Carry forward the distinction between fresh initialization and exact
restoration, along with the meaning and limits of these residual observations.
Unequal query and key/value head counts and trained-checkpoint serialization
remain later work.
