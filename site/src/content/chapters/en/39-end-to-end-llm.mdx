## One product connects every next-token decision

The complete model still answers the same question introduced near the start of
the course:

$$
P_\theta(z_{1:T})=\prod_{t=1}^{T}P_\theta(z_t\mid z_{<t})
$$

The sequence probability $P_\theta(z_{1:T})$ is a product of conditional
probabilities. Training minimizes the negative log of those conditionals;
validation selects $\theta$; final evaluation measures the already selected
$\theta$; and generation samples one new $z_t$ from the conditional distribution
given $z_{<t}$.

The factorization is a causal promise. The probability for position $t$ may
depend on $z_{<t}$, never on a later token. A frozen split makes the experimental
promise parallel to the mathematical one: later test evidence cannot flow
backward into tokenizer learning, updates, or selection.

{/* chapter-section:symbol-glossary */}

## Keep sequence position separate from pipeline stage

- $P_\theta$ is the probability distribution defined by the decoder.
- $\theta$ contains all learned parameter values chosen by validation loss.
- $z_{1:T}$ is one sequence from its first token through token $T$.
- $T$ is the number of tokens whose joint probability is being assigned.
- $\prod_{t=1}^{T}$ multiplies one conditional term at every position.
- $t$ is the current token position.
- $z_t$ is the observed token at that position.
- $z_{<t}$ is the complete earlier causal prefix.

The training step number is not $t$. A step updates $\theta$ from a mini-batch;
$t$ indexes a token inside the language-model factorization.

## From short count contexts to autoregressive Transformer LLMs

A count-based bigram estimates the next token from one preceding token and cannot share statistical strength through learned features or use the longer causal prefix.

[A Neural Probabilistic Language Model](https://www.jmlr.org/papers/volume3/bengio03a/bengio03a.pdf)
supports this bounded claim: Bengio and colleagues describe traditional n-gram generalization through short overlapping sequences and show a neural probability function that learns distributed word representations and benefits from longer contexts; their model is not a Transformer or this course pipeline.

[Attention Is All You Need](https://arxiv.org/pdf/1706.03762) supports a later
boundary: Vaswani and colleagues define the Transformer and mask decoder self-attention so a position cannot read later positions; their published architecture is an encoder-decoder model and does not define this course data, checkpoint, or generation policy.

[Language Models are Few-Shot Learners](https://arxiv.org/pdf/2005.14165)
supplies the scaled-LLM context: Brown and colleagues report GPT-3 as a scaled autoregressive language model and evaluate its task behavior without parameter updates at use time; scale and capability claims from that model do not transfer to this tiny teaching run.

Neural language models learned distributed token features and longer-context probability functions; the Transformer supplied masked self-attention, and later autoregressive Transformer language models scaled that training objective.

The capstone joins the complete evidence boundary used by an autoregressive decoder: data isolation, tokenizer learning, causal next-token updates, validation-only selection, untouched final evaluation, persistence, and stateful generation.

Return to the training-only alpha-one bigram as the frozen short-context baseline, then compare it with the validation-selected causal decoder on exactly the same previously unopened test targets.

Count n-grams provided a strong short-context baseline; learned distributed features and masked self-attention made longer learned computation possible, and scaled autoregressive Transformers became modern LLMs. This capstone demonstrates the same end-to-end responsibility boundaries at inspectable scale without treating one tiny loss win as a general quality claim.

The executable contrast is narrow: one-token count context against a four-token
causal decoder on this frozen corpus. A lower loss verifies this fixture. It does
not establish a universal architecture ranking or useful generation quality.

## Assemble APIs instead of copying algorithms

<code>run_capstone</code> starts by parsing the checked corpus and split. It
learns BPE from the training partition, encodes each document without joining
boundaries, fits the alpha-one bigram from the same training tokens, and builds
separate causal epochs for update, validation, and final evaluation.

Two decoder runs receive the same initialization and batch-order seed. Each
executes all $32$ updates. The implementation compares every training event,
loss checkpoint, optimizer state, selected step, and model bit. Only after that
replay agrees does <code>FinalEvaluator</code> consume its one local test
permission.

The selected model and step-$32$ optimizer enter one versioned checkpoint. Save
and load bytes must match, the restored BPE ranks must equal the learned ranks,
and prompt logits must agree bit for bit. The loaded model then runs cached and
complete-prefix generation from the same RNG state.

## Take ownership of the complete decoder

Every course component now participates in one functional program: frozen bilingual data becomes BPE tokens and causal batches, the decoder trains and is selected without test access, the held-out report beats its frozen bigram, the checkpoint restores exact state, and cached generation returns decoded text.

That completes the planned road to a modern decoder-only LLM at teaching scale.
You can now change one bounded piece—more context, a wider block, another
tokenizer budget, a different sampler—and identify exactly which data,
mathematical, training, evaluation, persistence, and inference evidence must be
re-established.
