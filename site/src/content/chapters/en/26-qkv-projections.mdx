## Predict three outputs from one sequence

Start with one batch containing two token states:

$$
X=\begin{bmatrix}1&2&-1\\0&1&2\end{bmatrix},\qquad
X\in\mathbb{R}^{1\times2\times3}.
$$

Use three distinct weights:

$$
W_Q=\begin{bmatrix}1&0\\0&1\\1&-1\end{bmatrix}.
$$

$$
W_K=\begin{bmatrix}0&1\\1&0\\-1&1\end{bmatrix}.
$$

$$
W_V=\begin{bmatrix}1&1\\1&-1\\0&2\end{bmatrix}.
$$

Before running the example, multiply the first token by each weight. The
expected vectors are $q_0=[0,3]$, $k_0=[3,0]$, and $v_0=[3,-3]$. The second
token should produce $q_1=[2,-1]$, $k_1=[-1,2]$, and $v_1=[1,3]$.

The three answers differ because the weights differ. Their batch and token
coordinates remain aligned.

{/* chapter-section:formula */}

## Project the final feature axis three ways

The complete forward rule is

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
$$

Its shape contract is

$$
X\in\mathbb{R}^{B\times T\times d_{model}}.
$$

$$
W_Q,W_K,W_V\in\mathbb{R}^{d_{model}\times d_{head}}.
$$

$$
Q,K,V\in\mathbb{R}^{B\times T\times d_{head}}.
$$

Every branch applies the same last-axis matrix operation independently at each
batch item and token position. It does not compare tokens. In particular, these
three projections alone produce no similarity scores, probabilities, causal
mask, or weighted value mixture.

For the frozen fixture, the complete result is

$$
Q=\begin{bmatrix}0&3\\2&-1\end{bmatrix},\quad
K=\begin{bmatrix}3&0\\-1&2\end{bmatrix},\quad
V=\begin{bmatrix}3&-3\\1&3\end{bmatrix}.
$$

{/* chapter-section:symbol-glossary */}

## Keep roles, axes, and dimensions separate

- $X$ is the hidden-state tensor entering self-attention.
- $B$ is the batch size and $T$ is the number of token positions.
- $d_{model}$ is the input feature width.
- $d_{head}$ is the output width for this one-head chapter.
- $W_Q$, $W_K$, and $W_V$ are independent learned weights.
- $Q$ is the query view: it will ask what each position should retrieve.
- $K$ is the key view: it will describe how each position can be matched.
- $V$ is the value view: it carries the content that a later mixture can retrieve.

The names do not perform attention by themselves. Also, this chapter does not
require $d_{model}$ to be divisible by $d_{head}$. That constraint appears only
when Chapter 30 splits and merges multiple heads.

## From learned alignment to self-attention projections

This history follows neural attention on the road to modern LLMs, not the
history of any programming language.

Earlier recurrent encoder-decoder models compressed the source into one fixed
vector. [Bahdanau, Cho, and Bengio, *Neural Machine Translation by Jointly Learning to Align and Translate*](https://arxiv.org/abs/1409.0473)
replace that bottleneck with differentiable alignment. At target step $i$, the
previous decoder state $s_{i-1}$ and each encoder annotation $h_j$ enter a
learned compatibility function, and the resulting weights mix annotations into
a context vector.

Additive encoder-decoder attention learns compatibility between a decoder state
and encoder annotations, relieving a fixed-context bottleneck but retaining two
distinct source streams rather than forming three views of one sequence.

Bahdanau, Cho, and Bengio compute each translation context as a weighted sum of
encoder annotations, with alignment scores produced from the previous decoder
state and each annotation.

It is useful to call the decoder state query-like and an annotation
key/value-like, but this is a retrospective bridge. Bahdanau and colleagues do
not use this chapter's query, key, and value terminology, three projection
matrices, equal head widths, or bias policy.

[Vaswani et al., *Attention Is All You Need*](https://arxiv.org/abs/1706.03762)
describe attention as mapping a query and key-value pairs to an output. They
apply distinct learned linear projections to queries, keys, and values. In
self-attention, all three inputs come from the same previous-layer sequence.

The Transformer formalizes attention with queries, keys, and values;
self-attention obtains all three from the same sequence and applies separate
learned projections before compatibility scores and value mixing.

Vaswani et al. define attention over queries and key-value pairs, linearly
project queries, keys, and values, and describe self-attention as relating
positions within one sequence.

Modern decoder-only LLMs use that same-sequence projection pattern before
causal attention. The bias-free rule, exact $[d_{model},d_{head}]$ orientation,
stable names, equal widths, fixture, and errors here are course choices rather
than requirements claimed by either paper.

A decoder-only Transformer projects every normalized token state into separate
query, key, and value feature spaces before computing causal self-attention.

## Compose three existing differentiable linear layers

`QkvProjections` owns three bias-free `Linear` layers. Construction initializes
query, key, and value weights in that stable order using one trial generator,
then commits the generator only after the complete layer is valid. Manual
construction checks each branch, shared dimensions, and unique names before
publishing the result:

The reverse fixture forms one scalar objective,

$$
L=\langle Q,U_Q\rangle+\langle K,U_K\rangle+\langle V,U_V\rangle.
$$

All three paths accumulate into

$$
\bar X=\begin{bmatrix}3&1.5&1.5\\-1.5&3.5&-5\end{bmatrix},
$$

while each branch keeps its own weight gradient. Central differences check all
six coordinates of $X$, $W_Q$, $W_K$, and $W_V$ with step $10^{-6}$ and
tolerance $2\times10^{-6}$. Empty batch and token axes remain connected to the

## Compare queries with keys and mix values next

The cumulative decoder now accepts a normalized hidden sequence with shape
$[B,T,d_{model}]$ and emits separate $Q$, $K$, and $V$ tensors with shape
$[B,T,d_{head}]$. Chapter 27 will turn those prepared feature views into one
unmasked attention head by computing scores, probabilities, and a value mixture.
