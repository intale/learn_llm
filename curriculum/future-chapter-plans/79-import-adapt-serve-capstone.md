### A tiny explicit successor, with no measured quality claim

Reuse71's orientation: base $W_0$ has shape $[d_{out},d_{in}]$, $A$ is
$[r,d_{in}]$, $B$ is $[d_{out},r]$, and $y=W_0x+(\alpha/r)B(Ax)$ for a
column input $x$. Choose the synthetic exact values

$$
W_0=\begin{bmatrix}1&0\\0&1\end{bmatrix},\quad
A=\begin{bmatrix}1&0\end{bmatrix},\quad
B_{SFT}=\begin{bmatrix}0\\1\end{bmatrix},\quad
B_{DPO}=\begin{bmatrix}0\\2\end{bmatrix},\quad
x=\begin{bmatrix}1\\1\end{bmatrix},\quad r=\alpha=1.
$$

Disabled output is $[1,1]^T$; SFT output is $[1,2]^T$; successor output is
$[1,3]^T$. The corresponding merged matrices are
$W_{SFT}=\left[\begin{smallmatrix}1&0\\1&1\end{smallmatrix}\right]$
and $W_{DPO}=\left[\begin{smallmatrix}1&0\\2&1\end{smallmatrix}\right]$.
Every value in this tiny multiply/add is exactly representable in FP32. The
successor contains the current complete factors; it is not an additional delta
to add on top of the SFT factors. Adding both corrections gives the wrong output
$[1,4]^T$. Applying the successor again to already merged $W_{DPO}$ gives
$[1,5]^T$. These distinct failures make the no-double-merge invariant visible.
The arbitrary toy factors illustrate lineage, not a real SFT/DPO gradient update.
