Теперь эталонная реализация со скалярными вычислениями получает из ID токенов дифференцируемые логиты следующего токена и среднее значение индексированной функции потерь. В главе 33 эта модель для CPU будет обучаться в ограниченном детерминированном цикле, а одно состояние будет выбрано только по функции потерь на валидационной выборке; эти этапы не подтверждают измеренные возможности более крупной LLM на ноутбуке.
