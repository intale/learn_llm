Graph-free evaluation must choose its recording policy before the model forward. Calling `value` or `detach` afterward would be too late because intermediate operations would already have created their parent edges. The immutable `AutogradContext` carries that policy explicitly: `recording()` permits graph construction, while `no_grad()` forbids new parent edges. Context-aware model and layer methods pass the same value down to every tensor operation; no hidden thread state needs to be entered or restored.

At operation-node creation, two conditions are required for a tracked result: the context must permit recording, and at least one parent must already track gradients. A no-gradient context therefore makes an operation over parameters untracked. A recording context does not make an operation over constants tracked. The context controls only newly created operations; it does not retroactively detach an existing `TensorValue` or erase that value's graph. Both policies still run forward arithmetic, shape validation, and finite-value checks.

`evaluate_no_grad` constructs one `AutogradContext::no_grad()` before iterating over the epoch's mini-batches and passes it to `DecoderModel::loss_with_context`. It computes a token-weighted epoch mean and proves that every batch loss is untracked. It snapshots gradient bits before evaluation and rejects the call if any bit changes. This is separate from `zero_grad`: the context controls edges created by future operations, whereas `zero_grad` clears gradients already accumulated on parameter nodes.
