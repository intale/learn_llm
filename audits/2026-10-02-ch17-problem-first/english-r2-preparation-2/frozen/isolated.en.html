For fan-in 2 and fan-out 2, target variance is 0.5, standard deviation is 0.707106781187, and uniform bound is 1.224744871392. Standard deviation measures distribution spread; the bound marks its endpoint.
For fan-in 4 and fan-out 2, target variance is 1/3, standard deviation is 0.577350269190, and uniform bound is 1.000000000000. Increasing the number of summed inputs reduces the requested weight spread under the compromise.
In the zero-weight SiLU graph, input x=[1,-1], equal output weights [1,1], and scalar backward seed one give both input-weight gradient columns [0.5,-0.5]^\top. SiLU is evaluated at zero, where its derivative is 1/2. The equal output weights give both units the same upstream factor; multiplying by the two input coordinates supplies the opposite signs.
The same implementation, starting generator state, shape, fan values, and construction order reproduce all tensor bits. The twelve-decimal display rounds those values and is not the strongest equality check.
With shape [2,2], fan-in 2, fan-out 2, and construction order unchanged, the selected seed-18 tensor values differ from those from seed 17. This one comparison does not prove that all possible seed/request pairs produce unique tensors.
The target weight variance is a property of the sampling distribution. A finite matrix can have a nonzero measured mean and a different measured variance without violating the rule.
decoder.block.0.attention.query.weight appears first, then token_embedding.weight. A clone shares the original tape leaf; an independently reconstructed equal tensor has another leaf.
The invalid name is rejected before widths or draws; zero fan-in is rejected before sampling. The caller receives trial state only on success. In the two-clone collection, the first occurrence is index 0 and the repeated occurrence index 1.
Vaswani et al. do not prescribe a parameter initializer. Attention-score and embedding scaling are operations in the forward model, not initial-value selection.
The forward/backward scale argument assumes independent zero-centered weights, independent zero-centered input features, and zero-centered arriving gradients, each group with its own common variance. Weights must be independent of the inputs and arriving gradients, and the activation is assumed symmetric and near-linear with unit slope. The target belongs to the sampling distribution; finite samples need not match it exactly. Nonlinearities, normalization, residual paths, depth, data, and optimization affect actual decoder signals, so no exact decoder-signal variance is guaranteed.

Chapter 17 terms for starting weight spread, equal-unit symmetry, and exact replay.
Fan-in The count of input coordinates whose weighted contributions are summed into each output.
Fan-out The count of output coordinates to which each input contributes.
Hidden-unit symmetry Identical hidden units receive equal gradients under equal downstream treatment; equal updates keep them identical.
Parameter initialization Assigning the trainable values from which later optimization starts.
Pseudorandom generator A state-driven deterministic algorithm that supplies random-like draws, not cryptographic security.
Reproducibility Recreating identical stored weights with the same implementation, generator state, request, and construction order.
Seed The generator's raw starting state before its first draw; the same state gives the same continuation.
Target variance The chosen spread of a weight distribution in squared weight units, not a finite matrix's measured spread.
Uniform bound The endpoint magnitude of the zero-centered uniform interval used to sample weights.
Xavier-style initialization Zero-centered sampling that balances forward and backward width effects under independence and near-linear assumptions.
